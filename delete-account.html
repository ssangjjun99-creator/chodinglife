삭제되는 데이터

계정 삭제 시 아래 데이터가 모두 삭제되며 복구할 수 없습니다.

  • 보호자 계정 정보 (카카오 또는 구글 계정 식별자, 이메일)
  • 가족 코드 및 보호자–자녀 연동 정보
  • 자녀 프로필 사진
  • 주간 스케줄, 숙제 목록과 완료 기록, 숙제 인증 사진
  • 포인트 적립·사용 내역, 주간 목표, 보상 설정
  • 응원 메시지, 도착 확인 기록
  • 푸시 알림용 기기 토큰(FCM 토큰)

위 기록 외에 별도로 보관하는 개인정보는 없습니다. 보관 기간이 지나면 지체 없이 파기합니다.

계정을 유지한 채 데이터만 지우려면

계정은 그대로 두고 이용 기록만 초기화할 수도 있습니다.

  • 앱 실행 → 부모님 탭 → 기타 → 데이터 초기화
  • 숙제·포인트·스케줄 기록이 전체 삭제되며, 로그인 상태와 가족 코드는 유지됩니다.
자녀 기기는 별도의 회원가입 없이 가족 코드로만 연동되므로, 보호자 계정을 삭제하면 자녀 기기의 연동도 함께 해제됩니다.
